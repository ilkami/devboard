# DevBoard

Веб-приложение для управления личными проектами программиста: задачи, сроки, технологии и прогресс в одном месте.

Стек: React 18 + TypeScript + Vite. Стили написаны на CSS-переменных, сторонних UI-библиотек нет.

## Требования

- **Node.js 18 или новее** — проверить версию: `node -v`
- npm (устанавливается вместе с Node.js)
- Интернет при первом запуске — для загрузки зависимостей

## Запуск

```bash
npm install
npm start
```

После старта открыть в браузере: **http://localhost:5173**

В терминале Vite печатает два адреса:

- `Local` — на этом компьютере;
- `Network` — адрес в локальной сети, по нему приложение открывается с другого компьютера.

Остановить сервер — `Ctrl + C` в терминале.

## Первый вход

Приложение открывается на экране входа. Нажмите **«Регистрация»** и создайте аккаунт: имя, email, пароль (не менее 8 символов). Затем войдите с этим email и паролем.

Аккаунты хранятся в локальном хранилище браузера, поэтому на другом компьютере или в другом браузере регистрацию нужно пройти заново.

## Если на компьютере нет Node.js

Откройте файл **`devboard-standalone.html`** двойным щелчком — это вся программа в одном файле, без установки и без интернета.

## Сборка

```bash
npm run build            # production-сборка в папку dist/
npm run build:standalone # один автономный файл в dist-standalone/index.html
npm run preview          # предпросмотр production-сборки
```

## Структура проекта

```
src/
  App.tsx           маршрутизация и защита разделов
  auth/             регистрация, вход, сессия
  components/       оболочка приложения и компоненты главного экрана
  pages/            экраны
  data/             демонстрационные данные
  styles/           дизайн-токены и стили
  utils/            вспомогательные функции
docs/
  plan-razrabotki.md  план разработки
  tz-devboard.md      техническое задание
```

## Разделы

Реализовано: главная страница (сводка по проектам, задачи, календарь дедлайнов, технологии, диаграмма прогресса), регистрация и вход.

Разделы «Проекты», «Задачи», «Календарь», «Технологии», «Отчёты» содержат описание функциональности и будут наполнены интерфейсом.
